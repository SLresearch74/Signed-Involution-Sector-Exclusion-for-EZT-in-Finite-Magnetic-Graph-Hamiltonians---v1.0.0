Paper-facing statements below deliberately omit workstation-stage names. Existing earlier theorems are inherited, not reproved or expanded by this classification audit.

Intrinsic exact dark channel -> perturbative opening (p,q) -> finite weighted response realization -> structured residual kernel and declared survival -> marked rank-one Song arithmetic -> block/edge coefficient ideals -> sufficient bounded classifier and sharp amplitude-blind obstruction.

The last result closes the scoped chain. No new framework layer is proposed.

## Inherited definition checks

The earlier lexicographic theorem uses p as first nonzero perturbation order and q as first nonzero Markov-moment index at that order, with 0<=q<n for its stated n-dimensional analytic channel. These are not silently redefined as a spectral multiplicity or a structured block count here. Its local source is the Stage C lexicographic-opening theorem.

The endpoint construction has dimension sum_k[(k-1)rank(A_k)+sum_theta rank(P_theta A_k)]. It need not satisfy the smaller scalar delay dimension sum_k k rank(A_k). The quotient by Kmax is minimal only among permissible quotients of that fixed declared model. Neither convention-independent global structured minimality nor equality of ordinary and structured reachability is asserted.

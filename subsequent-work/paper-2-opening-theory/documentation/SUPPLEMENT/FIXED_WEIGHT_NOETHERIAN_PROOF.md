# Fixed-weight Noetherian proof — standalone form

Fix a positive rational weight on `(d1,d2,d3,d4,t)`. Clear denominators by finite ramification and write

`d_r = c_r s^{b_r}`, `t = c_t s^a`,

with positive integers `a,b_r`. The pulled amplitude is

`K(s;c)=sum_{n>=0} A_n(c)s^n`,

where each `A_n` is a polynomial in the leading constants (or a Laurent polynomial on the coefficient torus). The coefficient ring is Noetherian. Hence the ideal generated by all `A_n` has a finite generating subset. If the finitely many generators vanish at a coefficient point, every coefficient vanishes and the pullback is exactly zero; otherwise the first survivor occurs among a finite set of indices.

This proves a finite coefficient-stratified decision for the fixed weight. It supplies neither an effective maximum index nor a uniform bound as the weight varies. Therefore it does not prove a finite global recursive atlas.

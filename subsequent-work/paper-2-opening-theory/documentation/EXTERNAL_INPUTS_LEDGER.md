# External inputs ledger

## Author-supplied local inputs

Paper I, Paper II R1.2, the strengthening audit, and the EA1/TF1/NP1/PB1/ARC1/MV1/GF1 releases were read from the workstation. Their authority paths and hashes are in `SOURCE_AVAILABILITY_LEDGER.md`.

## External bibliographic inputs

The internet was used only for prior-art discovery and metadata verification. Authoritative publisher, society, repository or primary arXiv pages were preferred. Search queries are in `PRIOR_ART_SEARCH_LOG.csv`; identifiers and claim roles are in `CITATION_VERIFICATION_LEDGER.csv`.

No external code, dataset or generated mathematical coefficient was downloaded into the release. Exact calculations use the locked local matrix and standard-library Python.

## Build tools

The build uses the existing workstation TinyTeX/TeX Live distribution and the Codex-bundled Python and PDF inspection libraries. These are tools, not scientific inputs, and are not included in the compact release archive.

# Paper II documentation index

The current repository status is recorded in
`R2_1_REPOSITORY_INTEGRATION_AUDIT.md`. The complete supplied-file decision
record is `SUPPLIED_ARTIFACT_INVENTORY.csv`.

The other files in this directory are preserved author-supplied audit ledgers
and editorial reports. Several describe the earlier R1.0 source bundle and are
therefore historical snapshots, not statements about the current repository
release. `START_HERE.md` is retained in that historical role. Where a historical
statement conflicts with the repository-integrated R2.1 manuscript or the
integration audit, the R2.1 files govern.

No audit file is a substitute for the Lean kernel. The formal trust boundary
and theorem-to-Lean map are in `../formalisation/README.md` and
`../formalisation/reports/`.

# Notation lock

| Symbol | Locked meaning | Prohibited reuse |
|---|---|---|
| `H0` | unperturbed 6×6 Hamiltonian | generic transfer matrix |
| `d=(d1,d2,d3,d4)` | actual internal diagonal coordinates | fixed ray direction |
| `v=(a,b,c,d)` | fixed or declared analytic direction | actual coordinate tuple without declaration |
| `epsilon` | scalar fixed-ray perturbation | moving-direction parameter |
| `eta` | analytic arc parameter; in Section 11 an adapted coordinate only when explicitly redeclared | Rees variable |
| `t` | physical/formal time | monomial pullback scale |
| `z` | resolvent spectral variable | time-series variable |
| `x=z^{-1}` | local resolvent variable at infinity | generic parent coordinate in theorem statements without declaration |
| `L` / `ell` | actual-coordinate / ray linear form | loss functional |
| `Q` | quadratic coefficient `d2 d4-d1 d3` | rational field |
| `R` | cubic numerator coefficient | Rees algebra, remainder, ray or cubic moment |
| `p` | perturbation order | time depth |
| `q` | time depth | perturbation order |
| `alpha,beta` | orders of `ell,Q` on an analytic arc | parent exponents in pullback theorem unless locally redeclared |
| `Lambda` | monomial exponent matrix | Hamiltonian spectrum |
| `I` | dark ideal or explicitly indexed face subset | identity matrix |
| `J` | tagged channel ideal | source index |

Vectors use lower-case Roman or Greek letters; ideals use upper-case Roman letters; evidence labels are small-cap textual annotations in the manuscript.

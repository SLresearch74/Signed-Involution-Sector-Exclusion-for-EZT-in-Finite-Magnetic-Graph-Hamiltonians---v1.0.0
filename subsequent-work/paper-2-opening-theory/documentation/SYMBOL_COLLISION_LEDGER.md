# Symbol collision ledger

## Resolved

- **R:** source bundles used `R` for the cubic numerator coefficient and occasionally in prose for other objects. The paper reserves `R` for the cubic coefficient; the Rees algebra is `\mathcal R(I)`.
- **d:** in actual coordinates `d` is a four-vector; on a ray `(a,b,c,d)` the final entry is scalar. The manuscript always declares which use is active.
- **eta:** ARC1 uses `eta` as the arc parameter; GF1 adapted coordinates use `eta` locally. The two sections are separated and each coordinate change is explicit.
- **x:** NP1 uses `x=z^{-1}`; PB1 uses generic parent variables. The generic theorem writes `x=(x1,...,xn)`, while model formulas retain the scalar `x`.
- **I:** MV1 uses `I(omega)` for an exposed vertex subset; GF1 uses `I=(L,Q)` for the ideal. Local section declarations prevent ambiguity.
- **weight coordinates:** ARC1 scale exponents `(a,b,c)` are not direction entries `(a,b,c,d)` inside the same displayed calculation; prose calls them scale exponents.

## Deliberately not merged

The scalar-ray direction and actual multivariate coordinates are kept as separate objects. Likewise moment-face forms `W_M` and amplitude-face forms `W_A` are never assigned one common symbol.

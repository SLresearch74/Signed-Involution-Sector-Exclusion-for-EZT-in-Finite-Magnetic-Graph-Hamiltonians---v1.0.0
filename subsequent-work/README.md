## Repository organisation

Each later research output should live in its own subdirectory with its own manuscript, citation metadata, validation notes, licensing information and archival identifier. This prevents the historical repository name and version from being mistaken for the identity of a later paper.

## Citation rule

Please cite each manuscript as a separate scholarly object. Once a paper has a Zenodo DOI, use that DOI as the canonical public citation and use the GitHub package as the reproducibility source.
